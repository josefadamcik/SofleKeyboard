BFS9000 is a bigger, more loaded take on Sofle, RP2040-powered — go big or go home. Per-key and underglow addressable RGB on both the main and side sections, optional OLED displays, and support for a capacitive trackpad, all from a single PCB that can be assembled in 16 different physical configurations (enclosures, plates and trackpad options).

   - MX switch hotswap sockets
   - per-key + underglow addressable RGB (front and side)
   - 128x64 OLED displays (optional)
   - capacitive trackpad support (optional)
   - RP2040 'drag and drop' flashing, QMK/Vial firmware
   - 16 physical configurations from the same PCB

BFS9000 was contributed by [Jesús Guillén](https://github.com/jguillen-lab).

[Build guide, BOM and full documentation are available here](https://github.com/jguillen-lab/BFS9000/wiki).
